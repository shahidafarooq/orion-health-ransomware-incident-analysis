# Orion Health Services – Ransomware Incident Analysis

## Project Overview

This project is a simulated cybersecurity incident analysis based on a ransomware attack affecting a healthcare technology organization.

The scenario involves a phishing email containing a malicious Excel attachment that led to unauthorized access, credential compromise, system disruption, and encryption of organizational files.

The purpose of this project was to practice analyzing a cybersecurity incident and preparing a professional report for an executive audience.

## My Role

**Cybersecurity Analyst (Entery level)*

For this simulated project, I analyzed the incident from a cybersecurity analyst perspective and documented the potential impact, indicators of compromise, affected systems, and recommended security measures.

## Organization Scenario

**Organization:** Orion Health Services
**Industry:** Healthcare Technology
**Employees:** Approximately 250
**Operating Region:** Australia and New Zealand

The organization provides cloud-based healthcare software to clinics and handles sensitive information.

## Incident Summary

The simulated incident began with a phishing email sent to a finance team member. The email contained a malicious Excel attachment.

Following the initial compromise, suspicious activity was identified within the organization's environment, including unusual outbound network traffic and employee account lockouts.

A ransom note was later discovered on a shared drive, indicating that ransomware had affected the organization's systems.

## Key Indicators of Compromise

The analysis identified several indicators associated with the simulated attack:

* Suspicious overseas login activity
* Credential harvesting activity
* Unusual outbound network traffic
* Multiple employee account lockouts
* Encrypted files using the `.orionlock` extension
* Ransom note appearing on a shared drive

## Systems and Data Affected

The simulated incident affected:

* File server
* HR systems
* Finance systems
* Backup server

Potentially compromised information included:

* Employee payroll records
* Patient appointment schedules
* Internal system credentials

## Security Analysis

The project focused on understanding how the initial phishing attack could develop into a wider ransomware incident.

The analysis considered:

* Initial access through phishing
* Credential compromise
* Lateral movement
* Data and system impact
* Backup security
* Incident response
* Security monitoring
* Access control
* Employee security awareness

## Recommended Security Measures

The report recommends several measures to reduce the likelihood and impact of similar incidents:

* Strengthen phishing awareness training
* Implement multi-factor authentication
* Improve endpoint and network monitoring
* Apply least-privilege access controls
* Protect and isolate backups
* Regularly test backup restoration
* Monitor unusual login activity
* Improve incident response procedures
* Maintain updated security policies and procedures
